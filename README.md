# Steam Rental Bot

Автоматизированная система аренды Steam аккаунтов с Telegram ботом.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
python install_requirements.py
```

### 2. Первоначальная настройка
```bash
python first_setup.py
```

### 3. Запуск бота
```bash
python main.py
```

Или используйте простой стартер:
```bash
python start.py
```

## 📁 Структура проекта

- `main.py` - Главный файл для запуска бота
- `install_requirements.py` - Скрипт установки всех зависимостей  
- `first_setup.py` - Скрипт первоначальной настройки
- `start.py` - Простой стартер с проверками
- `tg_utils/` - Утилиты Telegram бота
- `steam/` - Модули работы со Steam
- `requirements.txt` - Список зависимостей

## ✨ Особенности

- 🎨 Цветной вывод в консоли с colorama
- 🔧 Автоматическая установка зависимостей
- ⚙️ Простая первоначальная настройка
- 🔄 Автоматический перезапуск при ошибках
- 📱 Интеграция с FunPay API

## 🛠️ Требования

- Python 3.8+
- Токен Telegram бота
- Steam аккаунты для аренды
Bot For Steam Rent
